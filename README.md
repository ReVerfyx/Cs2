# Соль — абсолютно ненормальный CS2 chaos server

**Соль** — серверный режим для Counter-Strike 2, где обычного раунда почти не существует. Директор хаоса каждый раунд выбирает несколько несовместимых идей и запускает их одновременно.

Например: один игрок в каждой команде летает, террорист становится живой бомбой, плэнт висит над картой, по летающим работает ПВО, к игрокам летят дроны, один человек превращается в танк, сверху падают бочки, по карте едет стена из сейфов, а вокруг случайного игрока вращаются пять C4.

## Что уже есть

### Основной рандом

- 3–6 случайных аномалий на раунд;
- отдельный случайный летающий игрок в каждой команде;
- случайная карта каждые N раундов;
- каждый раунд дополнительно получает случайный «небесный мусор» из C4, мебели, сейфов и дронов;
- всё очищается и возвращается в норму между раундами;
- все тяжёлые визуальные сущности удаляются при конце/перезапуске раунда.

### Бомба и плэнт

- **тиммейт вместо бомбы**;
- террорист-бомба получает увеличенное HP;
- он может летать;
- цель находится прямо в воздухе;
- удержание внутри воздушной зоны заменяет плэнт;
- уничтожение живой бомбы отдаёт победу CT;
- визуальный C4 и маркер **«ПЛЭНТ В ВОЗДУХЕ»**;
- отдельная аномалия, которая физически переносит настоящие bombsite-триггеры A/B вверх;
- C4 на 10 секунд;
- C4 на 90 секунд.

### Авиация, ПВО и дроны

- по одному летающему игроку на T и CT;
- на карте появляются визуальные батареи ПВО;
- реальная видимая ракета ПВО летит к воздушной цели;
- ракета взрывается рядом с игроком и разбрасывает окружающих;
- дрон-камикадзе представлен отдельной Source 2 моделью;
- дрон физически летит по координатам к выбранному игроку;
- удар дрона создаёт взрыв и отбрасывание;
- интервалы ПВО и дронов настраиваются.

### Танки

- случайный танк в каждой команде;
- 350 HP;
- 100 брони;
- Negev;
- поверх игрока постоянно двигается визуальный корпус;
- отдельная визуальная башня следует за игроком;
- автоматическая танковая пушка раз в несколько секунд выбирает живую цель и отправляет видимый снаряд.

По умолчанию танк собирается из штатных моделей CS2, чтобы не требовать от клиента отдельный workshop addon. Модели можно заменить в конфиге.

### Большие трэш-события

- **метеоритный дождь** — сверху летят физические взрывающиеся бочки;
- **дождь из кур**;
- **чёрная дыра** — засасывает живых игроков к случайной точке;
- **мебельный торнадо** — стулья кружатся и подбрасывают людей;
- **стена из сейфов** едет через карту и сносит игроков;
- **орбитальные C4** вращаются вокруг случайного игрока;
- **все в небо**;
- **ракетные ботинки**;
- **перемешать всех** — координаты всех живых игроков случайно меняются местами.

### Оружие и физика

- оружейная рулетка;
- Zeus-only;
- Negev-only;
- Deagle-only;
- ножи;
- лунная гравитация;
- сверхтяжёлая гравитация;
- ледяной пол;
- бесконечные патроны;
- friendly fire;
- headshot-only;
- случайное HP от 20 до 300.

## Визуальные модели

Плагин регистрирует ресурсы через CounterStrikeSharp resource manifest и использует штатные ресурсы CS2:

- drone / turret: `models/props_survival/dronegun.vmdl`
- tank body / moving safe wall: `models/props_survival/safe/safe.vmdl`
- missile: `weapons/models/grenade/hegrenade/weapon_hegrenade.vmdl`
- meteor: `models/props/coop_cementplant/exloding_barrel/exploding_barrel.vmdl`
- flying furniture: `models/generic/terrace_set_01/terrace_chair_01.vmdl`
- C4: `weapons/models/c4/weapon_c4.vmdl`
- chickens: `models/chicken/chicken.vmdl`

Пути вынесены в конфиг. Можно заменить их на собственные workshop-модели позднее.

## Команды

```
css_salt
```

Добавляет ещё одну волну аномалий прямо в текущий раунд.

```
css_salt_status
```

Показывает текущую комбинацию хаоса.

```
css_salt_map
```

Сразу выбирает случайную карту из `MapPool`.

## Стек

- Linux CS2 Dedicated Server;
- Metamod:Source 2.x;
- CounterStrikeSharp;
- .NET 10;
- CounterStrikeSharp.API 1.0.376.

## Сборка

```bash
git clone https://github.com/ReVerfyx/Cs2.git
cd Cs2
dotnet publish src/Sol/Sol.csproj -c Release -o build/Sol
```

Скопировать `build/Sol` в:

```
game/csgo/addons/counterstrikesharp/plugins/Sol/
```

И выполнить:

```
exec sol_server.cfg
```

Полная установка с нуля описана в `SERVER_SETUP.md`. Есть и автоматический установщик:

```bash
bash scripts/install-plugin.sh /home/cs2/server
```

## Конфиг

После первого запуска:

```
game/csgo/addons/counterstrikesharp/configs/plugins/Sol/Sol.json
```

Настраиваются:

- минимальное/максимальное число аномалий;
- визуальные сущности;
- модель дрона;
- модель корпуса и башни танка;
- модель ракеты;
- модель метеора;
- модель воздушного плэнта;
- высота/радиус воздушного плэнта;
- частота ПВО;
- частота дронов;
- частота метеоров;
- число падающих кур;
- смена карт;
- `MapPool`.

## Карты

Пока плагин делает стандартные карты странными сам. Для следующего уровня можно добавить отдельный workshop map pack: кривые bombsite'ы в воздухе, комнаты с гравитацией, гигантские рампы, летающие острова и зоны для техники.

Сам код уже не привязан к конкретной карте: большую часть хаоса он строит относительно координат живых игроков.
