# Соль — CS2 chaos server

**Соль** — серверный chaos-mode для Counter-Strike 2. Каждый раунд директор случайно смешивает несколько аномалий, поэтому обычная карта превращается в полную дичь.

## Уже в ядре

- 2–4 случайные аномалии каждый раунд
- один случайный летающий игрок (noclip) в каждой команде
- **«тиммейт вместо бомбы»**: один T становится живой бомбой
- **воздушный плэнт**: живой бомбе надо удержаться в точке над картой
- **ПВО**: периодически захватывает воздушные цели
- **дроны-камикадзе**: предупреждение → удар/подброс/урон
- **танки**: по одному бронированному игроку на команду
- оружейная рулетка, Zeus-only, Negev-only, Deagle-only
- низкая/лунная/адская гравитация
- скользкий пол
- бесконечные патроны
- friendly fire
- headshot-only
- лотерея HP
- массовый подброс в воздух
- перемешивание позиций игроков
- короткий/длинный C4-таймер
- случайная смена карты через заданное число раундов
- команды тестирования `css_salt`, `css_salt_status`, `css_salt_map`

## Стек

- Linux CS2 Dedicated Server
- Metamod:Source
- CounterStrikeSharp
- .NET 8
- CounterStrikeSharp.API 1.0.376

## Быстрый запуск

```bash
git clone https://github.com/ReVerfyx/Cs2.git
cd Cs2
dotnet publish src/Sol/Sol.csproj -c Release -o build/Sol
```

Скопируй содержимое `build/Sol` в:

```
game/csgo/addons/counterstrikesharp/plugins/Sol/
```

А `cfg/sol_server.cfg` выполни через `exec sol_server.cfg` или добавь нужные параметры в свой server.cfg.

## Конфиг

После первого запуска CounterStrikeSharp создаст:

```
addons/counterstrikesharp/configs/plugins/Sol/Sol.json
```

Там можно менять количество аномалий, частоту ПВО/дронов, высоту воздушного плэнта, число раундов до смены карты и map pool.

## Важно про карты

Плагин умеет рандомизировать установленный map pool. Для workshop-карт сначала установи их на сервер, после чего добавь их реальные имена в `MapPool`.

## Архитектура

Ядро специально сделано расширяемым: новая аномалия — отдельный метод + одна запись в пуле событий. Поэтому сюда можно без боли добавить сотни режимов, NPC/пропы, кастомные модели танков/дронов и отдельные Hammer-карты.

## Статус

Первая рабочая основа. Следующая логичная стадия — визуальные сущности: реальные летающие дроны/ракеты ПВО, физические танки, движущиеся плэнт-зоны и набор специально собранных абсурдных workshop-карт.
